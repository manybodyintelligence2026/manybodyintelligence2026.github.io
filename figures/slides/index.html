Skill 2 of 5 · /schematic

Drawing schematic figures from code

editable vector graphics (SVG / PDF), not flat pixels
“Doing science is fun, but drawing the schematic figure that explains it has been challenging for us: we were never trained to do it, yet that figure is often the first thing a reader looks at.”
— Zhao & Wright, Automating schematic figure making (Yale LGW Lab, 2026)
Why code with a skill?
An image generator gives you flat pixels you cannot fix. A skill gives you editable vector graphics (SVG / PDF) together with the code that draws them.

Figure 1. The same request, “Draw Fig. 1 for this paper”, without and with the skill. With the skill, the drawing agent loads a folder of instructions (SKILL.md), drawing code, optional 3D kits, automatic checks and design references. Like every diagram in this post, this figure was drawn by the skill itself. — Zhao & Wright (2026)

Source & Figure 1: Zhao & Wright, lgwrightlab.github.io/schematic-figure (Yale LGW Lab, 2026, CC BY 4.0)

Getting started at 14:00

14:00–15:00 figures phase · lightning talks at 15:45
Step 1 · Download & let Claude install (30 s)

Install the 5 skills in your home folder

Download mbi2026-figure-skills.zip from resources.html and ask Claude Code to unzip & install them into ~/.claude/skills/. Never edit your team repo's .claude/ folder (that holds the hackathon logger).

Step 2 · Pick only what fits your project

Paste a starter prompt into Claude Code

Most teams start with Skill 1 (/figure-style) + Skill 3 (/render-and-look) for data plots, then add a schematic or HTML animation if helpful. Copy mbi.mplstyle as code/team.mplstyle so teammates match.

Step 3 · Check the physics & ship by 15:45

What to deliver

Reproducible scripts saving vector PDFs (code/fig_<name>.py → figures/<name>.pdf) for your 2-page note, plus clean visuals or HTML demos for your 15:45 lightning talk.
